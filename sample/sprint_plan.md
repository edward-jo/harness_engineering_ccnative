# AI Todo Manager 스프린트 계획

## 제품 개요

**제품명**: AI Todo Manager
**기술 스택**: React 18 (Vite) + FastAPI + SQLite + Claude API
**핵심 가치**: AI가 할일을 자동으로 분류하고 우선순위를 추천해 사용자의 인지 부하를 줄인다

## 스프린트 구성 (총 5개)

| 스프린트 | 테마 | 기능 수 | 기간 |
|----------|------|---------|------|
| 스프린트 1 | 백엔드 CRUD API | 5개 | 1주 |
| 스프린트 2 | 프론트엔드 기본 UI | 5개 | 1주 |
| 스프린트 3 | 고급 편집 기능 | 4개 | 1주 |
| 스프린트 4 | AI 통합 (핵심) | 4개 | 1.5주 |
| 스프린트 5 | 대시보드 및 배포 | 4개 | 1주 |

---

## 스프린트 1: 백엔드 CRUD API

**목표**: FastAPI로 할일 관리의 기본 CRUD 엔드포인트를 완성한다.

### 포함 기능
- `feat-001` 할일 추가 API (POST /api/todos)
- `feat-002` 할일 목록 조회 API (GET /api/todos)
- `feat-003` 할일 완료 토글 API (PATCH /api/todos/{id}/toggle)
- `feat-004` 할일 삭제 API (DELETE /api/todos/{id})
- `feat-005` SQLite 데이터베이스 초기화

### 검증 기준
- curl 또는 HTTPie로 4개 엔드포인트 모두 정상 호출 가능
- 유효하지 않은 요청에 대해 적절한 HTTP 상태 코드 반환 (400, 404)
- SQLite 파일에 데이터가 영속적으로 저장됨

---

## 스프린트 2: 프론트엔드 기본 UI

**목표**: React 18로 백엔드 API와 연동된 기본 할일 관리 화면을 구현한다.

### 포함 기능
- `feat-006` 할일 추가 폼 UI
- `feat-007` 할일 목록 렌더링
- `feat-008` 완료 체크박스 UI
- `feat-009` 할일 삭제 버튼 UI
- `feat-010` 반응형 레이아웃

### 검증 기준
- Playwright로 할일 추가/완료/삭제 플로우 E2E 테스트 통과
- 모바일(375px)과 데스크톱(1280px) 양쪽에서 레이아웃 깨짐 없음
- 빈 목록일 때 안내 메시지 표시

---

## 스프린트 3: 고급 편집 기능

**목표**: 필터링, 인라인 수정, 마감일 같은 실사용 편의 기능을 추가한다.

### 포함 기능
- `feat-011` 필터 탭 (전체/진행중/완료)
- `feat-012` 할일 인라인 수정
- `feat-013` 마감일 설정 기능
- `feat-014` 완료 항목 일괄 삭제

### 검증 기준
- 필터 탭 전환 시 URL 쿼리 파라미터 동기화
- 인라인 수정 시 Enter 저장, Escape 취소 동작
- 마감일 지난 항목은 빨간색으로 강조 표시

---

## 스프린트 4: AI 통합 (핵심)

**목표**: Claude API를 연동해 카테고리 자동 분류와 우선순위 추천을 구현한다.

### 포함 기능
- `feat-015` AI 카테고리 자동 분류
- `feat-016` AI 우선순위 추천
- `feat-017` 카테고리 뱃지 UI
- `feat-018` 우선순위 정렬

### 검증 기준
- "우유 사기" 입력 시 "쇼핑" 카테고리로 분류
- "내일 프로젝트 발표 준비" 입력 시 "high" 우선순위 추천
- Claude API 호출 실패 시 기본값("기타", "medium")으로 폴백
- 카테고리 뱃지가 8가지 색상으로 구분되어 표시

### AI 프롬프트 설계
- 모델: `claude-haiku-4-5` (빠른 응답)
- 카테고리 후보: 업무, 개인, 쇼핑, 건강, 학습, 여가, 가사, 기타
- 우선순위 기준: 마감일, 긴급성 키워드, 업무 맥락

---

## 스프린트 5: 대시보드 및 배포

**목표**: 통계 대시보드와 AI 브리핑을 추가하고 배포를 준비한다.

### 포함 기능
- `feat-019` 카테고리별 통계 대시보드
- `feat-020` AI 일일 브리핑
- `feat-021` 에러 처리 및 토스트 알림
- `feat-022` 배포 준비 및 환경 변수 관리

### 검증 기준
- 대시보드에서 카테고리별 원형 차트 표시
- 일일 브리핑이 3~5문장으로 오늘의 우선 할일 요약
- 네트워크 에러 발생 시 토스트 알림 노출
- `.env.example` 파일 제공, README에 배포 가이드 포함

## 기술적 의사결정

| 항목 | 선택 | 근거 |
|------|------|------|
| 프론트 빌드 도구 | Vite | 빠른 HMR, React 18 기본 지원 |
| 상태 관리 | React Query | 서버 상태 캐싱과 낙관적 업데이트 |
| 스타일링 | Tailwind CSS | 반응형 유틸리티 클래스 |
| ORM | SQLAlchemy 2.0 | FastAPI와 호환성 우수 |
| AI 모델 | claude-haiku-4-5 | 분류 작업에 충분한 성능, 저비용 |
| E2E 테스트 | Playwright | evaluator 에이전트가 사용 |

## 리스크 및 대응

- **Claude API 지연**: 비동기 큐 처리로 UI 블로킹 방지, 응답 대기 중 스피너 표시
- **API 비용**: 동일 제목 캐싱으로 중복 호출 방지
- **오분류**: 사용자가 카테고리/우선순위를 수동 수정 가능하도록 UI 제공
